# 常见问题 FAQ

> 🎯 这些问题在评论区、私信里被问了几十遍，答案都一样。集中写在这里，省得每个人重新走一遍弯路。

## 起步

### 我该买哪块板子？

只有一块预算：**野火 STM32F407 霸天虎**——站点 S 篇与 RTOS 移植全部按它写，资料最多、引脚全引出、调试接口标准。做语音/AIoT 才选 **立创·实战派 ESP32-S3**。两块都想买的话，先 STM32 后 ESP32：裸机地基打在前者更牢。清单与别花冤枉钱的配件见 [实物装备清单](/guide/hardware.md)。

### 没有数电/模电基础，能学吗？

能，但别硬撑。你需要的是"看得懂原理图、知道上下拉和上电顺序"这一档，不是会设计滤波器。缺的这部分在本站靠两处补：[手册地图](/guide/manuals.md) 教你查资料，[实验中心](/lab/index.md) 让你在板子上看到现象。

### SPL、HAL、寄存器，到底学哪个？

顺序是**寄存器 → 库**。先在寄存器层把一个外设的"配置寄存器 + 数据寄存器 + 状态寄存器"三件套走通，再回头看库把它封成了什么——本站每章的"库源码解析"就是这个对照。反过来先学 HAL，你会卡在"CubeMX 生成的代码为什么这样写"，而那是没有答案的问题。详见 [S15 SPL 库解剖](/stm32/15-spl-anatomy.md)。

### 能用 CubeMX / 图形化配置工具吗？

工作中能用，学习阶段先手写一遍。理由很实际：工具把引脚复用、时钟分频这些"会出错的决策"藏起来了，你只有先自己错过一次，之后才看得懂它替你做了什么选择。

## 环境

### Windows 够用吗？

够。本站全部工程在 Windows 上构建验证（工具链 + VSCode/命令行）。ESP-IDF 走官方安装器，注意路径不要带中文与空格。步骤在 [S0 环境搭建](/stm32/00-env.md) 与 [P0 环境搭建](/esp32/00-env.md)。

### 没有示波器/逻辑分析仪能做实验吗？

E01/E02/E05 用串口打印或 LED 就能验；E03/E06/E07/E08 需要仪器（示波器、毫安级电流测量）。不必一次买齐：先做不需要仪器的实验，等需要看波形时再补——预算顺序在 [实物装备清单](/guide/hardware.md) 里标了。

### 板子到手第一件事做什么？

点灯，而且要**知道自己在往哪个地址写什么**。（[实验 E01](/lab/e01-blink.md)）

## 学习路线

### 学到什么程度算入门？

三条检验：① 换一个没玩过的芯片，只看手册能在两小时内把 USART 收发跑起来；② 程序跑飞时，你有排查顺序而不只是重烧一遍；③ 能向别人讲清"中断里为什么不能调用阻塞函数"。这三条分别对应 S 篇、B4/S16、F 篇。

### FreeRTOS 和 RT-Thread 先学哪个？

先 FreeRTOS——内核小、能一行行读完，读完你就懂"RTOS 到底做了什么"。之后 RT-Thread 的重点变成设备框架与组件生态，那是另一套问题。对照结论在 [双实现对照](/rtos/compare/00-side-by-side.md) 与 [选型决策树](/rtos/compare/01-choose.md)。

### 为什么 C 篇要放在最前面？

因为指针、`volatile`、栈帧这三样不补上，后面每一章的"库源码解析"都会变成玄学。见 [C0 为什么嵌入式 C 是另一种 C](/c/00-c-in-mcu.md)。

### 章节显示"建设中"，还值得读吗？

骨架页的**结构、学习目标、先修关系、常见坑**已经写完，可以当提纲用；正文、动画与工程还没补齐。首页地图实心=成稿、虚线=建设中，数字由脚本全站统计，不会骗你。

## 内容与协作

### 数字和事实怎么保证不出错？

寄存器地址、引脚号必须有出处，写不出就标"以某手册某节为准"，禁止编数值；核对过的数值要有第二来源（CMSIS 头文件/官方手册）。这条纪律写在 [贡献指南](https://github.com/zhuguang-ZFG/mcu/blob/main/CONTRIBUTING.md)，未回填的坑也都在页面上明说。

### 发现错误怎么办？

开 Issue 或直接在每页右下角"在 GitHub 上编辑此页"提 PR。勘误是本项目的正式贡献类型，不是打扰。

### 可以转载/商用吗？

内容是 [Apache-2.0](https://github.com/zhuguang-ZFG/mcu/blob/main/LICENSE)，引用的上游源码遵守各自许可证且已注明出处；实物照片与图表请勿单独摘走。

### 为什么这个项目参考"通往AGI之路"？

学它的**开源、体系化、面向初学者**，但不学它把深度让渡给广度：这里每一个知识点都要追到寄存器、追到源码、追到示波器上的波形。说明见 [关于我们与致谢](/reference/about.md)。
