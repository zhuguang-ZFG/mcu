# S6 定时器 TIM：从数脉冲到发 PWM

> 🎯 TIM 是 STM32 最全能的外设：本质只是一个"会数数的计数器"，但配上预分频、自动重载、比较/捕获单元，它就能延时、发 PWM、测频率、读编码器——一招"计数"，十般变化。

## 本章精髓

1. 时基三件套：**PSC**（预分频，先把时钟降下来）、**CNT**（计数器本体）、**ARR**（数到几归零）——更新频率 = TIMclk / (PSC+1) / (ARR+1)，两个"+1"是新手必考题。
2. PWM 的本质是"比较"：CNT 与 **CCR** 比较，小了输出高、大了输出低（极性可配）——占空比 = CCR/(ARR+1)，改 CCR 就改占空比，硬件自动出波形，CPU 全程旁观。
3. 输入捕获是"拍照"：引脚边沿一到，硬件把 CNT 拍进 CCR——两次拍照的差值×计数周期=脉宽/频率，全程不用 CPU 掐表。

## 学习目标

- 手算任意目标的 PSC/ARR（如 1kHz、50Hz 舵机波），并说出 TIM 时钟来源（APB 倍频规则回 S2）。
- 配置一路 PWM 输出驱动霸天虎 RGB（呼吸灯效果），实测占空比与波形。
- 配置输入捕获测一路方波频率，与信号源标称值对比。

## 先跑起来（10 分钟 quick win）

TIM3 CH1 输出 1kHz/50% PWM 到 PF6（若 PF6 复用表无 TIM 通道，改用板载可用定时器通道引脚，以 datasheet 复用表为准），红灯立刻"半亮"——PWM 调光的直观体感。

## 板卡事实

- 定时器归属：TIM2–5/12–14 在 APB1（42MHz→倍频 84MHz），TIM1/8–11 在 APB2（84MHz→倍频 168MHz）（RM0090 §2/§7）。
- 引脚-通道映射以 **F407ZGT6 datasheet 复用表**为准（成稿时逐通道核对标注）。

## 记忆锚点

::: tip 一句话记住
**PSC 除一除，ARR 数一数，频率=(时钟÷俩加一)；PWM 靠 CCR 比一比，捕获靠边沿拍一拍。**
:::

## 常见坑

- **两个"+1"漏算**：1kHz 配成 999Hz 的隐形误差。
- **忘开 GPIO 复用 + CC 通道使能**：CCxE 位不开，引脚永远没波形（输出使能是独立一步）。
- **APB 倍频规则记错**：APB1 分频≠1 时 TIM 时钟×2——TIM2 按 42MHz 算全错，它是 84MHz。
- **ARR=65535 溢出盲区**：测低频时 CNT 溢出忘计，结果差一整圈。
