# S4 NVIC 与 EXTI：让按键来"打断"你

> 🎯 轮询是"每隔一会儿跑去门口看有没有快递"，中断是"快递按门铃"。门铃响了之后 CPU 做了什么——怎么去的、怎么回的、两个快递同时按铃谁先——这一章全部讲透。

## 本章精髓

1. 三层链路：**EXTI**（把引脚边沿变成中断请求）→ **NVIC**（按优先级仲裁、呈递给内核）→ **内核**（硬件压栈、取向量表跳转）——每一层都要单独配置，漏一层铃就不响。
2. 优先级两组数：抢占优先级（能不能打断别人）与子优先级（同时挂起谁先上）——NVIC_SetPriorityGrouping 把 4 位优先级切成两份，全家要用同一把尺子。
3. 中断现场是"硬件+软件"接力：硬件压 8 个字（动画），ISR 里要用更多寄存器就由编译器补压——所以 ISR 天生就是"轻功高手"，恋战必堵门。

## 学习目标

- 配通一条完整链路：PF6 输入→SYSCFG 选端口→EXTI 触发沿→NVIC 使能→ISR 里清挂起。
- 解释 EXC_RETURN 魔法值（0xFFFFFFFD）的作用与异常返回流程。
- 用两组按键实验验证抢占嵌套：低优先级 ISR 里延时，高优先级能否插入。

## 先跑起来（10 分钟 quick win）

在 00-blink 上加三行使能 EXTI0（外接按键或短接测试）：ISR 里翻转 PF6——按键一下，灯变一次。从"我去查"到"它来叫"的体感，一次建立。

## 板卡事实

- 向量表位置：EXTI0=IRQn 6、EXTI9_5=23、EXTI15_10=40（RM0090 §12.2）；内核寄存器（NVIC/SysTick/SCB）见 PM0214。
- SYSCFG_EXTICR 决定"EXTI 线接哪个端口"，别忘开 SYSCFG 时钟（RCC_APB2ENR bit14，RM0090 §7）。

## 记忆锚点

::: tip 一句话记住
**先 SYSCFG 选门，再 EXTI 设沿，后 NVIC 放行，ISR 进门先清挂起**——四层口诀，中断永不丢。
:::

## 实物实验

- 基础：按键中断点灯（quick win 完整版）；
- 进阶：EXTI0 低优先级（ISR 里 delay 1 秒），EXTI1 高优先级（ISR 翻转另一灯）——按住键 0 再按键 1，看灯 2 立刻响应：抢占嵌套眼见为实。

## 常见坑

- **忘清 EXTI_PR 挂起位**：进 ISR 就再也出不来，主循环彻底停摆——ISR 第一行就该清。
- **SYSCFG 时钟没开**：EXTICR 写了不生效，EXTI 死活不触发。
- **优先级分组混用**：SPL 默认组 2、RT-Thread 要求全抢占位（组 4）——移植 RTOS 时中断优先级"看起来一样行为不同"多源于此（F8/R7 联动）。
- **ISR 里调用不可重入函数**：printf/malloc 在中断里用，等着偶发死机（S7/F4 给出正确姿势）。

## 你做到了

- 中断从"会自动跳的函数"还原成"三层配置 + 两段压栈"的机制；
- 优先级与嵌套有了肌肉记忆——这是 RTOS 章节的地基之一。
