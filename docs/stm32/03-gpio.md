# S3 GPIO：七个寄存器位级图解

> 🎯 GPIO 是每个外设的"出发大厅"：不管什么高级功能（串口/SPI/PWM），最后都要从一个引脚进出。吃透这一章，后面每章的"引脚设置"环节你都能秒过。

## 本章精髓

1. 四个配置寄存器各管一维：**MODER**（输入/输出/复用/模拟，每脚 2 位）、**OTYPER**（推挽/开漏）、**OSPEEDR**（2~100MHz 边沿速度）、**PUPDR**（上拉/下拉/浮空）——配置一个引脚=按序填这四张表。
2. 三个数据寄存器分工：**IDR** 读真实电平、**ODR** 读写输出（读-改-写有隐患）、**BSRR** 原子置位/复位（高 16 位清、低 16 位置）——BSRR 是"改一位不扰邻居"的正解。
3. 复用（AF）是第二人生：AFRL/AFRH 每个脚 4 位选 AF0~AF15——引脚还是那个引脚，数据源从 ODR 换成外设（USART_TX/TIM_CH…）；datasheet 的复用表是唯一的真值。

## 学习目标

- 默写 GPIO 配置流程：开时钟→MODER→OTYPER→OSPEEDR→PUPDR→（复用则 AFRL/H）。
- 解释推挽 vs 开漏的应用场景（I2C 为什么必须开漏+上拉）。
- 完成 E01 的"反向实验"：把 PF6 从输出改成输入，读 IDR 观察悬空/上下拉差异。

## 板卡事实

- 霸天虎：RGB 红=PF6/绿=PF7/蓝=PF8，共阳低电平点亮；GPIOF 时钟=RCC_AHB1ENR bit5（出处：野火《寄存器点灯》）。
- 寄存器偏移（RM0090 §8.4）：MODER 0x00 / OTYPER 0x04 / OSPEEDR 0x08 / PUPDR 0x0C / IDR 0x10 / ODR 0x14 / BSRR 0x18 / LCKR 0x1C / AFRL 0x20 / AFRH 0x24。

## 实物实验

- 基础：[E01](../lab/e01-blink.md) 完成三色切换；
- 进阶：PF6 改输入+上拉，杜邦线对地短接，GDB 读 IDR bit6 从 1 变 0——亲手摸到"输入数据寄存器"。

## 常见坑

- **忘开 GPIOx 时钟**：寄存器全写不进去（读回全是 0），新手第一大坑，没有之一。
- **用 ODR 翻转单个引脚**：中断插在"读-改-写"中间就会丢状态——改位请用 BSRR。
- **OSPEED 盲目拉满**：边沿越快 EMI 越猛；LED/按键用 2MHz 足够，高速信号才需要 50/100MHz。
- **复用功能开了 AF 没换 MODER**：MODER 还在"通用输出"，外设根本接不进引脚——复用要成对配置（MODER=10 + AFRL/H 选号）。
