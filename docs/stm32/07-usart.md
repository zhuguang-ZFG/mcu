# S7 USART：波特率、状态机与 printf 重定向

> 🎯 点灯是"给芯片看"，串口是"听芯片说"——从此调试不用猜：`printf("x=%d\n", x)` 就是最朴素的示波器。这一章把"说"的成本算到每一位。

## 本章精髓

1. 波特率是"约定的时间片"：发送方每位占 1/115200 秒，接收方在 16 倍过采样的中点判决——BRR 寄存器的小数分频（DIV_Mantissa + DIV_Fraction）就是为了逼近这个时间片。
2. 收发靠状态位驱动：TXE（发送数据空）→ 写 DR；TC（发送完成）≠ TXE——移位寄存器还在吐；RXNE（收到）→ 读 DR。**每个状态位都对应硬件流水线的一级**，不理解就会"丢最后一个字节"。
3. printf 重定向的本质：newlib 的 `printf` 最终调 `_write(int, char*, int)`——我们在 `_write` 里把字节塞进 USART，C 库的豪华输出瞬间附体（回 [B0](../build/00-toolchain.md) 的钩子伏笔）。

## 学习目标

- 手算任意波特率的 BRR 值（含小数部分），并估算误差百分比。
- 写出阻塞版/中断+环形缓冲版两套收发（环形缓冲回 [C5](../c/05-func-pointer.md)）。
- 完成 printf 重定向，并解释 TXE 与 TC 等待时机的差别。

## 先跑起来（10 分钟 quick win）

USART1（PA9 TX/PA10 RX，AF7）115200-8-N-1，上电打印 `hello mcu`——串口助手第一次见到芯片的心跳。

## 板卡事实

- 霸天虎 USART1 引脚 PA9/PA10（板载 USB 转串口或外接 TTL 模块，以霸天虎原理图为准）；USART1 在 APB2（84MHz）。
- 寄存器（RM0090 §30.6）：SR 0x00 / DR 0x04 / BRR 0x08 / CR1 0x0C（UE/TE/RE/RXNEIE）/ CR2 / CR3。

| 小节 | 内容 | 四件套 |
|---|---|---|
| 帧格式 | 起始/数据/校验/停止位的时序图；8-N-1 的含义 | 配置 |
| BRR 手算 | 84MHz→115200 全程演算；误差%怎么估 | 配置 |

## 记忆锚点

::: tip 一句话记住
**写 DR 看 TXE，收字节等 RXNE，全发完认 TC；BRR=时钟除波特率，小数分频凑逼近。**
:::

## 实物实验

- [E02](../lab/e02-logic-uart.md)：分析仪抓 'A'(0x55) 波形，逐位读回 01010101——教科书般的方格旗；
- printf 重定向后把 [B5](../build/05-map-size.md) 的审计结果打印出来，对比体积变化（newlib 的"代价"亲眼所见）。

## 常见坑

- **TX/RX 接反**：TTL 是交叉（我 TX 接你 RX）；直连法分分钟教你做人。
- **共地缺失**：只接 TX/RX 不接 GND，数据全是乱码。
- **等 TXE 就关机**：最后一位还在移位寄存器里——断电前要等 TC。
- **中断里 printf**：重入+长耗时双重雷（S4 中断礼仪）；正确姿势：中断入队，主循环打印。
