- S0→S3 是"点灯三连"，先建立手感与信任；S4/S5 是 RTOS 的前哨；S6–S12 外设逐个击破，每章都有板上实验；
- 每个实验的装备与现象都登记在 [实验中心](../lab/index.md)。
