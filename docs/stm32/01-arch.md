# S1 F407 架构总览：为什么 0x40020000 是 GPIOA

> 🎯 背寄存器地址是最笨的学法。GPIOA 住在 0x40020000 不是天意，是 ST 画"城市地图"时划的门牌：Cortex-M4 统一编址 4GB，外设区从 0x40000000 起，AHB1 从 0x40020000 起，GPIO 每端口隔 0x400——GPIOA 自然就是 0x40020000。

## 本章精髓

1. 统一编址的世界观：Flash/SRAM/外设/内核寄存器全在一张 4GB 地图上，"访问外设"就是"访问某个地址段"——这就是 [C2](../c/02-pointer.md) 点灯公式合法的根源。
2. 总线矩阵决定"谁快谁慢"：内核经 I-Code/D-Code 取指取数，经 System 总线碰外设；AHB1（168MHz）/APB1（42MHz）/APB2（84MHz）三档速度，选错总线时钟源外设直接不干活。
3. 位带（bit-band）别名：把 SRAM/外设区的每一位映射成别名区的一个字——写别名地址=原子改一位，读-改-写隐患的官方解法。

## 学习目标

- 默画 F407 存储器映射骨架：0x08000000 Flash、0x20000000 SRAM、0x40000000 外设、0xE0000000 内核。
- 说出 GPIOA–GPIOF 基址的推导过程（AHB1 + 0x400×n），并能推 USART1（APB2 段）的位置。
- 会算位带别名地址并给出一个真实用例。

## 先跑起来（10 分钟 quick win）

GDB 里连读三个地址：`x/wx 0x40020000`（GPIOA_MODER）、`x/wx 0x40021400`（GPIOF_MODER）、`x/wx 0xE000ED00`（CPUID）——三个街区各看一眼，地图感立刻建立。

## 动画：一张矩阵上的五次访问

把本章精髓第 2 条播成电影：CPU 的 ICode/DCode/System 三个端口和 DMA 一起挂在 AHB 总线矩阵上，五个阶段各走一条真实路线——**取指**每拍打到 Flash（168 MHz 下 5 个等待周期，靠预取缓冲兜住，见 [S2](02-rcc-clock.md)）；**读 `USART1->SR`** 要穿 AHB→APB2 桥，两个时钟域之间还得同步；**DMA** 是矩阵上的第二台主机，搬得不占指令周期，但要跟 CPU 抢同一块 SRAM；最后一阶段故意走不通——**CCM RAM 只接到 CPU**，DMA 缓冲区放错了地方就是无声失败（[S8](08-dma.md) 有翻车实验）。分区归属依据 RM0090 的存储器映射表；等待周期那条是 S2 已核过的数字，不是估的。

## 动画：位带——一个位搬进一个字

精髓第 3 条的现场版。`GPIOF->ODR` 在 `0x4002_1414`，它的 8 个位在别名区各占一个字：`0x4242_8280`（bit0）到 `0x4242_829C`（bit7）。**地址是算出来的**——`0x4200_0000 + 0x21414×32 + 6×4 = 0x4242_8298`，`sh code/stm32/01-arch/probe.sh` 里三条 `_Static_assert` 替我们验算，编不过就是算错了。同一份 `-O2` 反汇编还把老问题摆了出来：`GPIOF->ODR |= 1u<<6` 编成 `ldr / orr.w / str` 三条，读与写之间有窗口；写别名字只剩 `movs #1` + `str.w [r3,#664]`，`BSRR` 同样一条 `str` 搞定。

## 记忆锚点

::: tip 一句话记住
**0800 是 Flash，2000 是 RAM，4000 是外设，E000 是内核；AHB1 上 GPIO，每口 400 一间房。**
:::

## 实物实验

- 位带实战：用别名地址翻转 PF6 的 ODR 位（不写 BSRR），观察红灯变化——体会"原子改一位"。

## 常见坑

- **APB1 当 APB2 用**：USART2/3 在 APB1（42MHz 上限），波特率算错源头常在总线归属记错。
- **位带去碰多比特字段**：位带一次只能改一位，改两位字段请回 BSRR/掩码。
- **以为所有地址都能读**：未实现的地址段访问直接 HardFault——GDB 乱读也会踩雷（S16 联动）。
