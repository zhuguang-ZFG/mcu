# P2 GPIO 与引脚矩阵：为什么 S3 的引脚能"任意映射"

> 🎯 STM32 上 USART1_TX 永远长在 PA9（或复用表给的固定备选）；ESP32-S3 上你可以对 SPI 说"MOSI 去 GPIO11，MISO 去 GPIO13"——**外设信号通过 GPIO Matrix 自由换岗**，就像公司总机把电话转到任意工位。

## 本章精髓

1. 两条路进引脚：**IO_MUX**（直连快车道：信号↔固定引脚，延迟低，仅少数高速信号必须走它）与 **GPIO Matrix**（交换矩阵：任意外设信号↔任意引脚，灵活但多一级延迟）——选型 = 速度 vs 布局自由。
2. 输入输出对称可配：输出=信号源选外设+引脚选目的地；输入=引脚信号路由到外设输入——`gpio_matrix_in/out` 的寄存器级视角（TRM 章节对照）。
3. 焊盘属性是独立一维：上下拉/驱动强度/开漏/毛刺过滤（S3 新增）——与路由无关，`gpio_set_pull_mode` 家族管这片。

## 学习目标

- 说出 IO_MUX 与 GPIO Matrix 的差异、各自代价，以及哪些信号**必须**走 IO_MUX（如部分高速 SPI 模式）。
- 用 IDF API 把一路 UART 信号分配到任意两个引脚并实测。
- 解释 strapping 引脚（BOOT 等）与普通 GPIO 的"上电角色冲突"，设计时如何避让。

## 记忆锚点

::: tip 一句话记住
**IO_MUX 是专线，Matrix 是总机；高速走专线，布局走总机；上下拉驱动找焊盘，strapping 脚上电别惹。**
:::

## 实物实验

- quick win 的 UART 换岗 + 把同一 TX 信号"一路两听"（Matrix 输入多路特性）接两路分析仪通道对照。

## 常见坑

- **strapping 脚当普通 IO**：GPIO0（BOOT）上拉电阻接错，板子每次上电进下载模式。
- **Flash/PSRAM 占用脚乱动**：八线 PSRAM 占用的 GPIO（S3R8 的 33~37 一带，以 TRM/模组手册为准）一碰就崩。
- **Matrix 路由后忘配焊盘方向**：信号路由对了，引脚还是输入态——输出使能是独立一步。
- **USB D+/D- 脚（19/20）当 GPIO**：用原生 USB 时这两脚有主——冲突外设先让位。
